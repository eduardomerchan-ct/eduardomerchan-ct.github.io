I'm working toward security engineering, with a focus on where AI and security meet. That means testing LLM applications for vulnerabilities before they ship, automating SOC triage with AI agents, and building hands-on labs to practice offense and defense.

Projects

AI Security

LLM Red-Team Harness
A pre-deployment security audit tool for LLM applications. It runs a YAML attack library mapped to the OWASP Top 10 for LLM Applications (2025) against a target chatbot, judges each response with rule-based and LLM-as-judge checks, and scores the severity of every finding.

SOC Incident Triage
A three-agent pipeline on Azure AI Foundry. It turns raw security logs into a CVSS-scored incident report: what the attack was, which systems were targeted, how severe each threat is, and how to remediate it.

AI Engineering

Policy Q&A Retrieval
A document-grounded RAG agent built in n8n, with a test suite that targets the retrieval layer itself: vocabulary mismatch, distractor density, table boundaries, and out-of-corpus queries.

Image to Recipe
A LangChain vision agent that identifies the ingredients in a photo and searches the web for a recipe that uses them.
